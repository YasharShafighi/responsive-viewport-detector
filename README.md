# 📐 Responsive Viewport Detector

> Live CSS Media Query demo with real-time viewport width detection

## ✨ Features

- **5 Responsive Breakpoints** with distinct colors:
  - 🟢 **Mobile (Portrait)** → up to 480px
  - 🔵 **Mobile (Landscape)** → 481–768px
  - 🟣 **Tablet** → 769–1024px
  - 🟠 **Desktop** → 1025–1919px
  - 🩷 **Ultra-Wide** → 1920px+

- 🌙 **Dark Mode Support** (auto-detects system preference)
- 🖨️ **Print Styles** optimized
- 📏 **Live Viewport Display** (floating counter)
- 🎨 **Glassmorphism Design** with smooth transitions
- 📱 **Fully Responsive** (works on all devices)
